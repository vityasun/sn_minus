# SlashMoon Core

Открытая модульная сборка дополнений сервера **SlashMoon** для режима **Fazbear's Hunt** (Garry's Mod).
Раньше это была закрытая сборка из 26 аддонов. Теперь это один автономный аддон без внешних API
и без обязательных зависимостей. Внутри аддона лежит собственная UI/модульная библиотека
**SlashMoon Lib**, её можно использовать и в своих проектах (см. [docs/LIBRARY.md](docs/LIBRARY.md)).

> Проект передан сообществу. Форкайте, правьте, присылайте улучшения.

---

## Установка

1. Скопируйте папку `addons/slashmoon_core` в `garrysmod/addons/` сервера.
2. Нужен режим **Fazbear's Hunt**: модули дорабатывают именно его.
3. Часть материалов и звуков оригинальной сборки (иконки хаба `sn_hub/*`, `vgui/sn/*`, звуки меток
   `sn/ping/*`, фон меню паузы) не входила в исходный архив. Без них интерфейс работает, но некоторые
   иконки и звуки будут пустыми. Положите их отдельным контент-паком (или в Workshop-коллекцию).
4. Перезапустите сервер. Конфигурация создастся в `data/slashmoon/config.json`.

Админ-системы подключаются автоматически, если установлены:

| Система | Что используется |
|---|---|
| **SAM** | `ply:HasPermission`, `sam.permissions.add`, команды `sam ...` |
| **ULX / ULib** | `ULib.ucl.query`, `ULib.ucl.registerAccess`, команды `ulx ...` |
| *ничего* | `IsAdmin()` / `IsSuperAdmin()` и встроенные уровни прав |

Приоритет: SAM → ULX → стандартная проверка. Прямых вызовов `sam`/`ulx` вне слоя
`SlashMoon.Admin` в коде нет.

## Админ-панель

Открыть её можно тремя способами:

- консоль: `slashmoon_menu` или `slashmoon_admin`;
- чат: `!slashmoon` или `/slashmoon`.

Возможности:

- переключатели модулей по категориям с поиском;
- настройки модулей: флаги, числа, строки, цвета;
- режим **«Применять сразу»** (live save) или применение кнопкой «Применить» / «Отмена».

Серверная консоль: `slashmoon_module <id> <0|1>`.

### Права

Права регистрируются в SAM (`sam.permissions.add`) или ULX (`ULib.ucl.registerAccess`).
Без админ-системы используется указанный уровень по умолчанию.

| Право | По умолчанию | Назначение |
|---|---|---|
| `slashmoon_menu` | superadmin | открыть админ-панель |
| `slashmoon_config` | superadmin | менять модули и настройки |
| `slashmoon_physgun` | admin | физган по игрокам |
| `slashmoon_noclip_invis` | superadmin | невидимость в noclip |
| `slashmoon_scoreboard_admin` | admin | админ-действия в табло |
| `slashmoon_postprocess` | admin | редактор постобработки (`sn_admin_pp`) |
| `slashmoon_movement` | admin | меню настроек движения |
| `slashmoon_mapvote` | superadmin | управление ротацией карт |
| `slashmoon_rounds_view` | admin | просмотр статистики раундов |
| `slashmoon_rounds_manage` | superadmin | управление типами раундов |
| `slashmoon_gf_force` | superadmin | принудительный Золотой Фредди |
| `slashmoon_endo_debug` | superadmin | отладка копий Эндо |
| `slashmoon_sfreddy_debug` | admin | отладка Shadow Freddy |
| `slashmoon_dances_force` | superadmin | принудительные анимации |
| `slashmoon_hub_money` | superadmin | выдача валюты хаба |
| `slashmoon_tasks_admin` | admin | админ-команды заданий |
| `slashmoon_tasks_editor` | superadmin | редактор точек заданий |
| `slashmoon_tasks_manage` | superadmin | управление фазами |

## Данные

| Путь | Что хранится |
|---|---|
| `data/slashmoon/config.json` | включённые модули и их настройки |
| `data/slashmoon/api.json` | (необязательно) адрес и ключ вашего собственного API |
| `data/slashmoon/round_types.json` | история типов раундов |
| SQLite `slashmoon_hub_players`, `slashmoon_hub_promos` | баланс, покупки и промокоды хаба |

Совместимость со старыми данными сохранена: `data/sn_tasks/`, `fh_maplist.txt`,
`ronni_player_editor/` читаются по прежним путям.

## Хаб

Хаб (F4) работает на **локальной экономике** в SQLite сервера. Приватный API не нужен.
В настройках модуля задаются:

- название валюты и стартовый баланс;
- цены анимаций;
- промокоды;
- список серверов для кнопки «ИГРАТЬ»;
- открытие хаба при входе;
- водяной знак.

---

## Что убрано по сравнению с закрытой сборкой

- **Зависимости:** SAM, SUI, eChat и eLib (esclib). Остались только мягкие проверки через `SlashMoon.Compat`.
- **Внешние эндпоинты:**
  - приватный API и whitelist;
  - регистрация через Discord;
  - матчмейкинг;
  - загрузка и покупка LMS-треков;
  - удалённый список бустеров.

  HTTP/JSON-утилиты остались (`SlashMoon.HTTP`, `SlashMoon.JSON`, `SlashMoon.API`), но адреса в коде не зашиты.
  Ссылки для LMS и бустеров задаются в настройках модулей.
- **Мёртвый код:**
  - заглушка магазина кастомных моделей;
  - неиспользуемый `security_fh_patch`;
  - пустой файл эффектов клоуна;
  - отладочные `print`/`PrintTable`.
- **Интерфейс:** все меню переписаны на `SlashMoon.UI`. Сторонние UI-библиотеки не используются.
- **Бинды:** F4 закреплён за хабом. Меню движения открывается командой `fh_movement_menu`.

## Библиотека для разработчиков

SlashMoon Lib включена в аддон `slashmoon_core` и лежит отдельным аддоном в
[`addons/slashmoon_lib`](addons/slashmoon_lib) — для тех, кому нужна только библиотека без модулей режима.

Исходник один — внутри `slashmoon_core`. `addons/slashmoon_lib` руками не правится: после
изменений библиотеки пересоберите её, линтер проверяет, что копия актуальна.

```sh
python3 tools/build_lib.py           # пересобрать addons/slashmoon_lib
python3 tools/build_lib.py --check   # проверить, что копия актуальна
```

Библиотека включает:

- модульную систему с безопасным включением и выключением;
- слой прав (SAM/ULX/fallback);
- конфиг;
- HTTP/JSON;
- UI-компоненты: окна, кнопки, переключатели, слайдеры, поля ввода, скролл, вкладки, попапы;
- тему и масштабирование.

Демо всех компонентов: команда `slashmoon_ui_demo` на клиенте. Полное API описано в [docs/LIBRARY.md](docs/LIBRARY.md).

## Разработка

```sh
tools/lint.sh    # заголовки, синтаксис, глобалы и актуальность addons/slashmoon_lib (нужны lua5.1 и luacheck)
```

Соглашения:

- первая строка каждого `.lua` файла: `-- Written for: SlashMoon. By: VIKA & Ronni`;
- всё живёт в пространстве имён `SlashMoon`;
- никаких отладочных `print`, для логов используйте `SlashMoon.Log` / `SlashMoon.Debug` (`slashmoon_debug 1`).
